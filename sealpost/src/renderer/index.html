addy.io aliases

        
        
Writing through an addy.io alias puts the real address inside the To address: shop+sam=example.org@example.com goes to sam@example.org. With this on, Sealpost encrypts to, searches for and assigns the key of that real address. The To address stays as it is, so the mail still goes through addy.io. addy.io's own domains and the domains of your "Send as" addresses are recognised by themselves.

        
        
        
        
Data folder: %APPDATA%\Sealpost — back up the keyring folder there (or export your secret key) so you never lose access to encrypted mail.

      

      
      

        
Sync with my web server

        
Keeps your accounts, contacts, PGP keys and settings the same on every PC, using the Sealpost Sync files on your own website. Everything is encrypted on this PC with your vault passphrase before it is sent — your server can't read any of it.

        

      

      
      

        
Offline mail

        
Keeps an encrypted copy of recent mail on this PC so you can read, search and write without a connection. Messages you send while offline wait in the Outbox and go out automatically. The copy is encrypted to your app-lock PIN.

        

      

      
      

        
Backup & restore

        
One file with your accounts (incl. passwords), settings, contacts and all PGP keys, locked with a backup passphrase. Use it to move to a new PC or recover after a disk failure. Keep it somewhere other than this PC (USB drive, cloud storage).

        

        

          
          
        

      

      
      

        
App lock

        
Ask for a PIN (or Windows Hello) when Sealpost opens, after inactivity, and when Windows locks. Recommended if you use "Remember passphrase".
